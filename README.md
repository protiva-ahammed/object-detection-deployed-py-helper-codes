To count the similar stuctured densely stacked products from uploaded images by the staff member during the inventory management lot counting in warehouses.
Helpers code are for followings:
1. mainly from data preparation,
2. data resizing for different object detection models,
3. image conversion from heic to jpg,
4. conversion of data from yolo to xml format to experiment the performance and train in tensolflow models, to reduce memory usage while trainning,
5. use of augmentation as data pre-processing
6. Use of GAN to check how it perform and increase the traing data volume and check how much rigor the performance of models with noisy-data
7. added requirements, docker file to automate running the trainging process
8. tain the dataset in yolo,yolo-ns,tensorflow models
9. the tainned weights have been converted in onnx format to deploy
